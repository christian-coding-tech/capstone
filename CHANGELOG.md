## 2026-10-18

- Improved teacher and student dashboard navigation on mobile with horizontally scrollable status tabs, clearer touch targets, and a more compact layout for dashboard actions and filters.
- Moved the student's personal ID QR code into a dedicated dialog opened by a QR icon button. The dialog can be dismissed with its close button, by tapping outside, or with Escape.
